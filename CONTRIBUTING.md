# Contributing

Issues and patches are welcome, especially from other Meteor Lake (`8086:7D55`) machines.

- **Send source, not binaries:** a diff against WTLIntelGfx v0.0.47 (commit `a3fd73ed`), and a small test that shows the bug, if you can.
- **Plugin, accelerator and kext changes:** these can be carried here as patches in `metal-stack/` once they're built and tested on this machine. Fixes that help every XeGfx user are also worth sending upstream to [WTLIntelGfx](https://github.com/watchthelight-labs/WTLIntelGfx).
- **Licences:** changes to plugin and accelerator code stay under PolyForm Noncommercial 1.0.0 (no commercial use). New scripts, tests and docs here are BSD-2-Clause unless you say otherwise. See `NOTICE`.
- **Testing:** say what hardware and macOS build you tested on, and what you saw.
